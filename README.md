# Neon Coast

A restrained neon dark theme for VS Code. Most code stays white, and color only marks what you scan for.

| Role | Color |
| --- | --- |
| Default text | `#ffffff` |
| Keywords, numbers, booleans | `#f78fe6` |
| Functions and methods | `#0ed5d9` |
| Strings | `#6aeabd` |
| Types and classes | `#5aa9ff` |
| Comments | `#7a7a7a` |
| Background | `#1e1e1e` |

No italics anywhere, including comments and parameters.

## Install locally

1. In VS Code, open the Extensions view.
2. Click the `...` menu and choose **Install from VSIX...**
3. Pick `neon-coast-theme-0.2.0.vsix`.
4. Run **Preferences: Color Theme** and select **Neon Coast**.

## Develop

Open this folder in VS Code and press `F5` to launch an Extension Development Host with the theme loaded. Edits to `themes/neon-coast-color-theme.json` apply live.
